# 📱 GITEGO KIDS WORLD — Android App (APK / Google Play)

Iyi folder (`mobile-android/`) irimo project ya **Capacitor Android** ihujwe ako kanya na **`https://gitego-kids-world.onrender.com`**.

## Uko ukora Android APK kuri Mudasobwa yawe

### Ibisabwa
- **Node.js 18+** (uramaze kuyigira!)
- **Android Studio** (cyangwa Android SDK)

### Commands zo gukora APK
```bash
cd /home/gitego/Downloads/projects/children-project/mobile-android
npm install
npx cap add android
npx cap sync android
npx cap open android
```
Muri **Android Studio**:
- Kanda **Build → Build Bundle(s) / APK(s) → Build APK(s)** (kuri `.apk` yo gusangiza abantu ako kanya), cyangwa **Generate Signed Bundle (.aab)** yo gushyira kuri **Google Play Store**!

## 💡 Uburyo bwihuse utagombye Android Studio (PWA)
Kuri Android telefoni iyo ari yo yose, fungura **`https://gitego-kids-world.onrender.com`** muri Chrome → kanda menu `⋮` → **Install app** — ihita iba app kuri telefoni ako kanya!
